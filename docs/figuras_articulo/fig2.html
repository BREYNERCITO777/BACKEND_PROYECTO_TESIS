Python 3.10 · OpenCV · Ultralytics · YOLOv8s (v5) · Docker, CPU or GPU

  • Shared model, batched inference, up to 5 analyzed frames/s per camera
  • Sends only detections and one evidence image

Alert flow

1The agent reads each RTSP stream in its own thread and keeps only the latest frame.
2YOLOv8s analyzes the new frames of all cameras in one batch; detections above the threshold are sent.
3The backend checks the token, threshold and cooldown, then stores the incident and the alert.
4MongoDB keeps incidents, alerts, cameras, users and settings.
5The alert is broadcast to every connected dashboard over WebSocket.
6The operator sees the evidence image and decides; the system never acts on its own.
