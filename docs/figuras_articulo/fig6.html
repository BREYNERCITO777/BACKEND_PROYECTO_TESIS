Sentinel AI: Operator Dashboard

React single-page application: real-time alerts, cameras, incidents and evidence

AuthProvider (context/auth-context)

Login, token check with GET /auth/me on page load, role (Admin / Operator) and allowed modules · useAuth()

App routes (React Router 7, one URL per module)

Public route

Login /login
Returns to the page the user tried to open

Protected routes (session required)

AlertsProvider (app/providers/alerts-context): loads the alert history, listens to the WebSocket, counts unread alerts and opens the incoming-alert window with the evidence image · useAlerts()
Layout: AdminSidebar (modules by role, unread badge) · Topbar (alert bell, user menu, logout)
Dashboard/dashboard
Summary of cameras, incidents and alerts
Cameras/cameras
Status, RTSP settings, start / stop
Incidents/incidents
Filtered table, evidence detail, download
Evidence/evidence
Gallery of evidence images
Alerts/alerts
All / unread / read; mark as read
Settings · admin/settings
Confidence threshold and detection options
Users · admin/users
Accounts, roles, activation
Dashed border: Admin role only

HTTP client

api/http.ts (axios) · api/base.ts

Adds the JWT to every request; API address taken from REACT_APP_API_BASE or derived from the browser location. Services: alerts, cameras, incidents, users, settings

WebSocket client

websocket/alerts.ts · native browser WebSocket

Connects to /api/v1/ws/alerts and passes each new_alert event to AlertsProvider

REST + JWT

FastAPI backend

/api/v1

REST endpoints (JSON + JWT) and WebSocket /ws/alerts

Technology

  • React 18 + TypeScript
  • Tailwind CSS, shadcn/ui (Radix)
  • React Router 7
  • axios (REST)
  • Native WebSocket (no socket.io)
  • sonner (notifications)
  • recharts (dashboard charts)

Deployment

Static build served by Nginx on the municipal server, which also forwards /api and the WebSocket to the backend (prototype: Vercel)

Human in the loop

The incoming-alert window shows the evidence; the operator decides and marks the alert as read
